# Segurança

## Versões mantidas

A série 0.5.x recebe atualmente correções de segurança.

## Relato de vulnerabilidades

Não abra uma issue pública para vulnerabilidades que possam expor dados. Relate a falha de forma privada pelo recurso **Security Advisories** deste repositório no GitHub.

Nunca envie cofres, chaves, backups `.dmsbackup`, arquivos CSV ou HTML reais. Um relatório útil pode informar a versão afetada, o ambiente, os passos mínimos para reproduzir com dados sintéticos, o impacto observado e uma sugestão de correção, sem incluir dados sensíveis.
