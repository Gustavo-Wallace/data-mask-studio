O que é o DMS?

Proteção prática para conjuntos de dados sensíveis

O Data Mask Studio é uma aplicação desktop para Windows destinada à proteção de dados sensíveis em arquivos CSV e conteúdo HTML local. Ele cria tokens determinísticos para que valores repetidos possam continuar correlacionados durante uma análise.

As informações originais ficam em um cofre local criptografado. A reversibilidade é controlada por meio desse cofre e de suas chaves protegidas, em vez de ser uma propriedade exposta por cada token.

Segurança e privacidade

Controles locais com funções criptográficas explícitas

O DMS oferece mascaramento determinístico com restauração controlada por meio de um cofre local criptografado. Ele não afirma que tokens individuais sejam reversíveis ou garantam anonimização irreversível.

HMAC-SHA256

Identificadores determinísticos

Os tokens derivam de autenticação criptográfica com chave, incorporando o prefixo configurado e o valor original.

AES-256-GCM

Proteção autenticada do cofre

As informações originais armazenadas no cofre são criptografadas e autenticadas contra alterações indevidas.

Windows DPAPI

Chaves locais protegidas

As chaves locais são protegidas para o usuário do Windows. O processamento é local, sem telemetria ou sincronização automática de dados sensíveis.
